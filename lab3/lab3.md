# Информационная система авиастроительного предприятия — Анализ бизнес-процессов (AS-IS)

---

## Задание 1. Описание ключевых процессов

---

### Основной процесс: Производство (сборка и испытание) авиационного изделия

| Параметр | Описание |
|---|---|
| **Цель** | Произвести авиационное изделие по технической документации, провести серию испытаний и передать принятое изделие |
| **Инициатор** | Плановый отдел предприятия (по производственному заказу) |
| **Входные данные** | Производственный заказ, конструкторская документация, нормы расхода материалов, состав персонала, расписание участков |
| **Выходные данные** | Готовое изделие, протокол испытаний, акт приёмки ОТК, производственные отчёты |
| **Участники** | Начальник цеха, начальник участка, мастер, бригадир, рабочие (сборщики, токари, слесари, сварщики), инспекторы ОТК, испытатели, начальник лаборатории, операторы оборудования |
| **Ожидаемый результат** | Авиационное изделие, прошедшее все стадии сборки и испытаний, принятое ОТК и оформленное надлежащей документацией |

---

### Вспомогательный процесс 1: Управление кадрами и движением персонала

| Параметр | Описание |
|---|---|
| **Цель** | Обеспечить актуальный учёт персонала, состава бригад, их назначений на участки и цеха |
| **Инициатор** | Отдел кадров предприятия |
| **Входные данные** | Личные дела сотрудников, категории персонала (инженеры, технологи, техники, рабочие), приказы о назначении, табели рабочего времени |
| **Выходные данные** | Актуальный кадровый состав цехов/участков, составы бригад, сведения о бригадирах, мастерах и начальниках участков |
| **Участники** | Отдел кадров, начальники цехов, начальники участков, бригадиры |
| **Ожидаемый результат** | Актуальная база данных персонала с привязкой к цехам, участкам и бригадам; возможность формирования отчётов по кадровому составу (запросы 3, 4, 6, 7 из задания) |

---

### Вспомогательный процесс 2: Управление испытаниями изделий в лабораториях

| Параметр | Описание |
|---|---|
| **Цель** | Организовать и провести серию испытаний собранного изделия в испытательных лабораториях, задокументировать результаты и использованное оборудование |
| **Инициатор** | ОТК / начальник цеха по завершении сборки изделия |
| **Входные данные** | Собранное изделие, программа испытаний, перечень доступного оборудования лаборатории, состав испытателей |
| **Выходные данные** | Протоколы испытаний (положительные/отрицательные), акты о выявленных дефектах, сведения об использованном оборудовании и задействованных испытателях |
| **Участники** | Начальник испытательной лаборатории, испытатели, операторы оборудования |
| **Ожидаемый результат** | Подписанный протокол испытаний с заключением о соответствии изделия требованиям; данные о лабораториях, оборудовании и испытателях в ИС (запросы 10–13) |

## Задание 2. BPMN-диаграммы

**Диаграмма 1** — Основной процесс «Производство авиационного изделия» (4 дорожки: Отдел планирования → Цех/Участок → ОТК → Испытательная лаборатория).

**Диаграмма 2** — Вложенный подпроцесс «Проведение серии испытаний в лаборатории» (3 дорожки: Начальник лаборатории → Испытатель → Оператор оборудования).

## Задание 3. Анализ основного процесса — выявление проблем

| Возможная проблема | Причина | Последствие |
|---|---|---|
| **Ручное назначение бригад на участки** (ручной учёт в бумажном журнале) | Отсутствие автоматизированной системы управления назначениями | Ошибки при распределении бригад, задержки начала работ, невозможность оперативного контроля загрузки |
| **Дублирование ввода данных об изделии** | Данные об изделии вносятся повторно в плановый отдел, в цех, в ОТК и в лабораторию независимо | Несоответствия в данных между подразделениями, избыточный ручной труд, риск несогласованности записей |
| **Узкое место на этапе ОТК** | Один инспектор ОТК проверяет несколько изделий последовательно, нет параллельного контроля | Очереди на приёмочный контроль, задержки в производственном цикле |
| **Ручное оформление дефектных актов** (бумага) | Отсутствие цифровых форм и электронного документооборота | Потеря документов, задержка возврата изделия на доработку, отсутствие накопленной статистики дефектов |
| **Задержки при перемещении изделия между участками** | Ручная координация перемещений, отсутствие автоматических уведомлений следующему участку | Простои бригад и оборудования, срыв производственного расписания |
| **Отсутствие онлайн-контроля статуса изделия** | Учёт ведётся в бумажных журналах или разрозненных электронных таблицах без единой ИС | Невозможность получить актуальный статус изделия в реальном времени, задержки при принятии управленческих решений |
| **Ручная фиксация результатов испытаний** (бумажный журнал) | Испытатели записывают результаты от руки без использования электронных форм | Ошибки, описки, потеря данных, невозможность автоматического анализа и формирования статистики испытаний |
| **Избыточный ввод данных о составе бригад** | Состав бригад и назначения вводятся заново при каждом новом изделии | Потеря времени, ошибки, расхождение данных между отделами |
| **Отсутствие системного контроля прохождения всех участков** | Нет механизма автоматической проверки завершённости всех этапов (участков) по изделию | Риск пропуска этапа, неполная сборка, срывы сроков, выпуск несоответствующей продукции |
| **Отсутствие планирования загрузки персонала** | Распределение рабочих по участкам осуществляется вручную без системы планирования | Простои при нехватке нужных специалистов, задержки производства, нарушение сроков |
